## 개별 환경 용어

### 코드를 쓰고 실행하는 용어

#### 파이썬(Python)

- 뜻 : 컴퓨터에게 일을 시킬 때 쓰는 말(프로그래밍 언어) 가운데 하나
- 설명 : 컴퓨터는 “0”,”1”로 이루어진 기계어만 알아듣고, 파이썬은 사람이 이해하기가 쉽게 만든 용어

#### 스크립트(Script)

- 뜻 : 컴퓨터에게 시킬 일을 순서대로 적어 둔 파일 하나
- 설명 : 메모지에 할 일들을 적어두듯, 컴퓨터가 순서대로 실행 해야 할 명령어들을 담아둔 파일

#### IDE (아이디이 / Integrated Development Environment)

- 뜻 : 코드를 직접 쓰고 그 자리에서 바로 실행해 보는 프로그램
- 설명 : 필요한 도구를 다 모여있듯, 코드를 편리하게 작성과 테스트할 수 있도록 갖춘 통합 작업 공간

#### 터미널(Terminal)

- 뜻 : 마우스 대신 글자로 명령어를 직접 입력하는 검은 창
- 설명 : “이 프로그램 실행해줘!”라고 직접 글자 주문을 넣어서 컴퓨터를 조종하는 통로

> **왜 마우스 대신 글자로 시키나?**
> 
> 
> 
> - GUI (Graphical User Interface)
>     - 뜻 : 마우스로 버튼을 직접 클릭해서 컴퓨터를 조작하는 방식
>     - 특징 : 누구나 쉽게 배우지만, 반복적인 대량의 작업 처리하거나 자동화하기 한계 있음
> 
> - CLI (Command Line Interface)
>     - 뜻 : 명령어를 직접 입력해서 컴퓨터를 조작하는 터미널 방식
>     - 특징 : 복잡한 명령이나 반복 작업을 정확하게 처리하며 자동화에 매우 유리
> - **CLI 왜 굳이 사용할까?**
>     1. **대량의 반복 작업을 한 번에 끝낼 수 있다. (자동화)**
>     2. **컴퓨터의 작업을 아끼고 더 빠르게 작동할 수 있다.**
>     3. **원격(멀리 있는) 컴퓨터를 다룰 때 필수적이에요**

### 기능을 찾아 설치하는 용어

- 뜻 : 컴퓨터가 프로그램이나 파일을 찾으러 뒤져보는 폴더 목록
- 설명 : 명령을 내렸을 때, 수많은 폴더 중에서 어디를 먼저 확인해야 할지 알려주는 경로 리스트

#### 패키지(Package)

- 뜻 : 남이 미리 만들어 둔 유용한 기능들의 묶음
- 설명 : 직접 처음부터 코드를 짜지 않고, 다른 사람이 미리 만들어 놓은 기능들을 가져다 쓰는 단위

#### pip(핍)

- 뜻 : 패키지를 내려받아 설치하는 명령어
- 설명 : 필요한 기능을 자동으로 찾아 내 컴퓨터에 다운로드하고 설치해주는 실행 도구

#### 가상환경(venv, 벤브)

- 뜻 : 프로젝트 하나만 쓰는 별도의 패키지 창고
- 설명 : 여러 프로그램을 만들 때 서로 꼬이거나 충돌하지 않도록 작업공간을 따로 분리해주는 환경
